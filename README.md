# PlayGround

## Dead Frequency

A Three.js first-person, round-based co-op zombie survival game set at the abandoned Blackpine Relay Station.

Requires **Node.js 22.12+** and npm.

```sh
npm install
npm run dev
```

Open **http://localhost:3000**. Choose **Deploy solo**, or **Play with friends** to host/join a room for up to four survivors. Use WASD to move, mouse to aim, left mouse to fire, right mouse to aim down sights, R to reload, E for supplies, and Escape to pause.

- [Play instructions and production hosting](GAMEPLAY.md)
- [Architecture and module contracts](ARCHITECTURE.md)
- [Asset and library credits](CREDITS.md)
- Live development progress: **`/progress.html`**

`npm run build` produces the production bundle. `npm run preview` serves it with the co-op relay. `npm test` runs the real-WebSocket integration checks.
