# PlayGround

## Tribes: Frontier

A playable first-person 3D capture-the-flag browser game inspired by Tribes. Ski snowy slopes to gain momentum, spend jetpack energy to fly, fire explosive projectile discs, and capture the enemy flag against a team of bots.

### Run

```sh
npm install
npm run dev
```

Open **http://localhost:3002**. The live build log is at **/progress.html**.

`npm run build` produces the static game and progress page in `dist/`.

### Controls

| Control | Action |
| --- | --- |
| WASD | Move and steer |
| Mouse / arrow keys | Look |
| Hold Shift | Ski; accelerate downhill and preserve momentum |
| Hold Space | Jetpack; release to recharge energy |
| Left click | Fire the Spinfusor's explosive disc |
| Esc | Pause and release the mouse |
| R / Restart | Start a fresh match |

Touch the red flag and bring it to the blue base. Your blue flag must be home to score. First to three captures wins, or highest score after eight minutes. Mouse control activates when you deploy. Touch devices have on-screen movement, ski, jet and fire buttons, with drag-to-look.

### Build process and references

See [the quality bar](docs/quality-bar.md) and the live build log for independent reviews, rendered screenshots, and playtest evidence. Reference gameplay: [official skiing tutorial](https://www.tribes3rivals.com/how-to-play) and [IGN's official Tribes 3 gameplay](https://www.youtube.com/watch?v=P9bvc1RyeME). The tutorial reference image is attributed to Prophecy Games. Game geometry and effects are procedural originals, rendered with Three.js/WebGL.
