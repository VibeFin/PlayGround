# DEAD FREQUENCY

Original co-op arcade-horror survival game. Abandoned Blackpine relay station, 1986. Art direction: cinematic teal fog, cold moonlight, ochre tungsten windows, weathered concrete, analog field-radio UI, chartreuse accents. No extremist imagery. Browser-native procedural assets.

## Module contracts

- `src/world.js`: `createWorld(THREE, scene)` returns `{ colliders, spawnPoints, playerSpawn, update(dt,time), setPower?(enabled) }`. colliders are `{minX,maxX,minZ,maxZ}` axis-aligned horizontal boxes. Walkable area x/z [-24,24]. Floor y=0. Player eye y=1.7. Station concentrated rear of courtyard (z=-8 to -22), center sightlines open. Camera menu position (13,7,18), target (0,2,-7). Detailed landscape and station visible there.
- `src/game.js`: `createGame({THREE,scene,camera,world,audio,onEvent})` returns `{start(),update(dt,input),shoot(),reload(),interact(),getState(),getSnapshot(),applySnapshot(data),applyRemoteShot(data),setAuthority(bool),reset()}`. Input `{keys:Set,lookX,lookY,firing,aiming}`. onEvent(type,data) delivers HUD events. State `{health,ammo,reserve,score,kills,wave,enemies,phase,phaseTime,weapon,stamina,interaction}`. camera movement managed here when playing. Expose player position in state or use camera.position. Health 100. Host authority in multiplayer: host simulates enemies and snapshot sync; guest local camera/weapons and sends shot rays. `shoot` emits `shot` data `{origin:[x,y,z],direction:[x,y,z],damage}`; guest forwards via networking. `applyRemoteShot` resolves host hits. Snapshot excludes local player.
- `src/audio.js`: `createAudio()` returns `{unlock(),setVolume(value),setMuted(bool),update(dt,state),play(name,options),dispose()}`. Procedural Web Audio. names shoot, empty, reload, hit, kill, hurt, wave, start, buy, step, death.
- `src/network.js`: `createNetwork({onStatus,onPeers,onSnapshot,onShot,onEvent})` returns `{host(),join(code),leave(),sendState(data),sendSnapshot(data),sendShot(data),sendEvent(data),getState()}`. promises host/join resolve room code. state `{connected,room,id,isHost,peers}`. callbacks peers array `{id,position,yaw,health,...}`. Real websocket relay in `server.mjs`, Vite dev middleware at port 3000 (env PORT override), production serve dist. Host leaves => session ends cleanly, no migration needed.
- `src/main.js` + `src/style.css`: owned by integration agent. Full-screen canvas with designed deployment menu, briefing, settings, co-op room modal, playing HUD, pause and game over, live progress link. Main updates network peer geometry and tracks settings.
- `public/progress.html` polls `public/progress.json`. Evidence must distinguish implemented from browser-verified. No fabricated comparisons.

Builders own only assigned modules. Communicate contract changes before editing shared modules. All edits via apply_patch. Favor readable modules, robust resize, pointer-lock escape, restart cleanup, bounded particles and draw calls. Tests cover real behavior, no claims of AAA parity without evidence.
